# Achievement Badge NFT (ERC721)

## Project Description
Achievement Badge NFT is a simple ERC721-style smart contract developed using Solidity. This project demonstrates how blockchain technology can be used to issue digital achievement badges as NFTs.

## Features
- Mint Achievement Badge NFTs
- Track Total Badges Issued
- Lightweight NFT Smart Contract
- Beginner-Friendly Implementation

## Technologies Used
- Solidity
- Remix IDE
- MetaMask
- Remix VM

## Deployment Steps
- Open Remix IDE  
- Create `AchievementBadgeNFT.sol`  
- Paste the smart contract code  
- Compile using Solidity `0.8.20`  
- Select `Remix VM` environment  
- Deploy the smart contract  
- Execute `mint()` function

This project demonstrates the basic implementation of an ERC721-style NFT smart contract for blockchain-based achievement badge systems.
